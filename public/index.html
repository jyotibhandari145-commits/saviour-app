Emergency Response Information:

Fire Emergency Protocol:

  • Evacuate immediately via nearest exit
  • Proceed to designated assembly point
  • Do not use elevators
  • Report to emergency coordinator

Network Failure Protocol:

  • Use hardwired phones for communication
  • Check physical bulletin boards for updates
  • Report critical issues via emergency PA system
  • Proceed to nearest information desk for assistance
